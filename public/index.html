biliup 后端 事件来源
日志监听与主播名解析都从这个地址读取,保存后自动重连。默认 http://localhost:19159,但 biliup 端口可能不同(如 -p 参数、Docker 映射、反代),请按实际填。Docker 部署的 biliup 一般填 http://host.docker.internal:19159 或 http://<容器名>:19159。
安全 网页端访问令牌
设置后,局域网内其他人无法查看/修改你的配置与推送。令牌会保存在浏览器 localStorage,服务重启不失效。请妥善保管——遗忘只能直接改 config.json。
Telegram 推送
双向控制 （Telegram 里发 /status、/add、/pause 等命令管理 biliup）
发送格式为 HTML，含主播名 / 直播间链接 / 时间 / 原始日志。测试前请先保存配置。启用双向控制后，配置的 Chat 可在 Telegram 直接发命令（发送 /help 查看命令列表）。
告警 疑似空录制 / 磁盘空间不足
空录制检测：新增录制文件小于阈值即告警；磁盘预警：剩余空间低于预警线即告警（24 小时内最多一次）。检查依赖 biliup 后端可达；磁盘探测仅在与 biliup 同机部署时有效，不可用时自动跳过。
Webhook 推送 自定义 POST JSON，可配多个
Webhook 收到 JSON：event / type_label / streamer / url / time / message 等字段，另附 text 纯文本摘要，兼容企业微信 / 钉钉 / 飞书等常见机器人格式。
事件开关
